# LRE Mobile Final 1.7.0

الهدف الرئيسي:
تقليل عدد الأرقام المطلوب لعبها مع قياس مقدار التغطية التي نفقدها أو نحتفظ بها.

الجديد:
- Smart Reduction page.
- يجرب حدود Top 25 إلى Top 500.
- Coverage Efficiency = نسبة الإصابة المقاسة ÷ نسبة الإصابة العشوائية لنفس K.
- Sweet Spot Finder يفضّل أقل قائمة تحقق التغطية المطلوبة مع أعلى كفاءة.
- زر لتطبيق العدد المقترح مباشرة على صفحة Predictions.
- يعرض عدد الأرقام المستبعدة من أصل 1000.
- Midday و Evening منفصلان.
- كل خصائص 1.6.0 محفوظة: Full 000–999, Source-Month research, Historical Backtest, الألوان الحالية.

مهم:
الاقتراح التلقائي في 1.7.0 يستخدم الاختبار التاريخي المقفول الموجود داخل التطبيق. لا توجد أي ضمانات مستقبلية.
الاستبعاد حسب سنة+شهر آخر ظهور لن يصبح Hard Exclusion على مستوى الرقم إلا بعد توفر تاريخ آخر ظهور لكل رقم داخل بيانات التطبيق وإثباته في Walk-Forward.
