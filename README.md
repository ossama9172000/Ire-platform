# LRE Mobile MVP

## التشغيل
1. فك ضغط الملف.
2. افتح مجلد المشروع.
3. شغّل خادمًا محليًا:
   - Windows/Mac/Linux: `python -m http.server 8000`
4. افتح المتصفح على: `http://localhost:8000`
5. على الموبايل يمكن فتح الرابط من نفس شبكة Wi‑Fi باستخدام IP الكمبيوتر.

## الوظائف
- عرض Midday وEvening.
- Top 50 / Top 100 / Top 150.
- إدخال نتيجة يدويًا.
- تقييم النتيجة وتخزينها داخل المتصفح.
- لوحة أداء مبسطة.
- Research status.

## ملاحظة
هذه نسخة MVP تجريبية تعمل محليًا. الربط بموقع رسمي يحتاج مصدرًا محددًا ومراجعة شروط استخدامه أو API الخاص به.
