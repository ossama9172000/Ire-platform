# LRE Mobile Final 1.8.0

الجديد:
- Smart Reduction ظاهر مباشرة داخل صفحة Predictions.
- مفتاح تشغيل/إيقاف واضح.
- اختيار نموذج الاختبار A/B/C/D/E.
- اختيار أقل تغطية مطلوبة من 20% إلى 50%.
- يعرض العدد المقترح، نسبة التغطية التاريخية، وعدد الأرقام المستبعدة من أصل 1000.
- زر واحد يضع العدد المقترح مباشرة في Result count.
- إصلاح عرض سنوات Behavior window عند اختيار English.
- تحسين شريط التبويبات على الشاشات الصغيرة ليصبح أفقيًا وقابلًا للتمرير.
- كل ميزات 1.7.0 و1.6.0 محفوظة.

تنبيه:
العدد المقترح مبني على الاختبار التاريخي المقفول المخزن داخل التطبيق؛ ليس ضمانًا للسحب القادم.
